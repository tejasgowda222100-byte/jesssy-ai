JESSY AI WEBSITE — UBINTZE TECH

Files:
- index.html: website content
- style.css: responsive design
- script.js: mobile menu and preview chat
- favicon.svg: browser icon

PUBLISH WITH GITHUB PAGES:
1. Upload these files directly to the root of the public GitHub repository named jessy-ai.
2. Commit the files to the main branch.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. After deployment, the site should be available at:
   https://tejasgowda222100-byte.github.io/jessy-ai/

IMPORTANT:
The chat area is a front-end preview, not a live AI service. To provide real AI responses, deploy the FastAPI/Ollama backend to a suitable server and connect it securely. Do not put API keys or private credentials in these website files.
